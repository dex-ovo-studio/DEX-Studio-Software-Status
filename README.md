## 软件介绍

### Navio

**代理客户端 · Windows x64 · 公开测试**

提供订阅管理、代理组切换和主题设置。支持安装版与免安装版，具体配置、升级及迁移步骤见使用指南。

[下载当前版本](https://github.com/dex-ovo-studio/Navio/releases/tag/v1.0.0-beta.7) · [使用指南](https://github.com/dex-ovo-studio/Navio/blob/main/docs/guide.md) · [更新日志](https://github.com/dex-ovo-studio/Navio/blob/main/CHANGELOG.md) · [历史版本](https://github.com/dex-ovo-studio/Navio/releases)

### Mystery

**盲盒与抽奖桌面软件 · Windows x64 · 正式版**

Mystery 是 D.E.X Studio 旗下的盲盒与抽奖软件。当前版本为 **2.1.0**，继续提供维护与问题反馈渠道；现有安装包保留历史 D.E.X 品牌标识。

[下载当前版本](https://github.com/dex-ovo-studio/DEX-Studio-Software-Status/releases/tag/mystery-v2.1.0) · [官方网站](https://mystery.mydex.top) · [安装说明](#mystery-guide) · [历史版本](#mystery-history)

### Tune

**便携 Windows 调试工具 · 0.8 内部原型**

整合硬件信息、系统调试、游戏库整理和参数应用流程，支持随 U 盘携带。目前没有公开安装包。

[项目介绍](https://github.com/dex-ovo-studio/DEX-TUNE) · [开发状态](https://github.com/dex-ovo-studio/DEX-TUNE/blob/main/STATUS.md)

### Rovelio · 驭途

**摩托车智能座舱 · Rebuild 01 开发原型**

探索音乐、地图与语音交互。现有原型仍需完善语音唤醒和设备验收，目前没有公开车机镜像。

[项目介绍](https://github.com/dex-ovo-studio/DEX-Rider) · [开发状态](https://github.com/dex-ovo-studio/DEX-Rider/blob/main/STATUS.md)

## 支持说明

| 状态            | 含义                                       |
| :-------------- | :----------------------------------------- |
| 🟢 **常规更新** | 提供常规版本更新、维护与问题反馈渠道。     |
| 🔵 **稳定支持** | 当前版本继续维护，暂不安排常规功能更新。   |
| ⚪ **停止支持** | 不再提供版本维护，迁移安排以项目公告为准。 |

支持状态不等同于在线服务可用率、实时监测或响应时限。公开测试与正式版属于发布阶段，与支持状态分别标注。

## Support

| Maintenance stage | Meaning |
| :--- | :--- |
| **Regular updates** | Routine releases, maintenance and feedback channels; currently Navio |
| **Stable support** | Maintenance for the current release, with routine feature updates on hold; currently Mystery |
| **End of support** | No further maintenance; migration plans follow project announcements |

Maintenance stage is separate from release maturity. This page is not a live uptime monitor or a response-time commitment.

Include the app version, operating system and reproduction steps; omit account credentials and private information.
