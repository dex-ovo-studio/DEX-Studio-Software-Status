## 状态说明

### 维护状态

| 状态 | 含义 |
| :--- | :--- |
| 🟢 持续维护 | 继续提供版本更新或问题修复。 |
| 🟡 维护暂停 | 暂停常规更新，恢复时间以正式公告为准。 |
| ⚪ 停止维护 | 不再提供常规更新，并提供迁移说明。 |

### 发布阶段

| 阶段 | 含义 |
| :--- | :--- |
| 公开测试 | 已提供公开下载，仍在收集反馈和完善功能。 |
| 正式发布 | 已发布正式版本，支持范围以软件文档为准。 |

核对日期表示最近一次版本信息核验日期。维护状态由项目维护者确认，不根据提交频率自动判断。
