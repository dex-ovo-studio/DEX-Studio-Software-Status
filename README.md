## 支持说明

| 状态            | 含义                                       |
| :-------------- | :----------------------------------------- |
| 🟢 **常规更新** | 提供常规版本更新、维护与问题反馈渠道。     |
| 🔵 **稳定支持** | 当前版本继续维护，暂不安排常规功能更新。   |
